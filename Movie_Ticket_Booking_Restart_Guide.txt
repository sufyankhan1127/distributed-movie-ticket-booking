============================================================ A. BEFORE
STOPPING TODAY: PUSH YOUR CODE TO GITHUB
============================================================

1.  Open a NEW IntelliJ terminal and run:

cd D:-movie-ticket-booking git status

2.  Review the files shown. Make sure you are NOT committing:

-   .env files containing passwords or secrets
-   generated build output such as target/
-   IDE-specific files you do not want in the repository

If .env or secrets appear in the files to be committed, stop and fix
.gitignore before continuing. Never paste secret values into GitHub.

3.  Stage and commit the project:

git add . git status git commit -m “Implement movie inventory booking
and payment services”

If Git says there is nothing to commit, the changes may already be
committed.

4.  Push to GitHub:

git push origin main

If your current branch is not main, run git branch --show-current and
push that branch instead: git push origin YOUR_BRANCH_NAME

If Git asks you to sign in, complete GitHub authentication in the
browser. Do not share your password or token in chat.

5.  Verify the push by opening the repository URL above and checking
    that the latest commit and files are present.

============================================================ K. STOPPING
EVERYTHING ============================================================

For each Spring Boot service terminal, press: Ctrl+C

After stopping the Spring Boot services, to stop Docker containers too:

cd D:-movie-ticket-booking docker compose down

This stops containers but preserves named Docker volumes unless you
explicitly remove them. Do NOT use docker compose down -v unless you
intentionally want to delete the persisted Docker volumes/data.
